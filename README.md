# eeg-clean-pipeline

Config-driven EEG cleaning and band-power pipeline: raw PhysioNet `.edf` in, clean Parquet out.

> **Status: work in progress.** Built step by step in public.

## Goal

Take raw, messy EEG recordings from the [PhysioNet EEG Motor Movement/Imagery](https://physionet.org/content/eegmmidb/1.0.0/) dataset and turn them into clean, structured brainwave metrics.
